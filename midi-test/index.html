QS MIDI Test

A set of short tests that show what your Alesis QS or QuadraSynth (keyboard or rack) can tell a computer over MIDI. They only listen and read: nothing is written to your unit, and nothing on it is changed or erased. Run all of them or just the ones you like, then send the results to Project Q, a free set of apps for these instruments. It helps make them work with more models.

1Connect

  • Use Chrome or Edge (Firefox and Safari can't do this).
  • Connect your MIDI interface both ways: the unit's MIDI Out to the interface's In, and the interface's Out to the unit's MIDI In.
  • Close other music programs (a DAW, SoundBridge): on Windows only one program can use a MIDI port at a time.
Is it a keyboard or a rack?

2Choose the tests and press Run

Run goes through every ticked test, the quick ones first. Each test also has its own Run button.

If the unit stops answering during a test, the page stops at once. Switch the unit off and on, and everything on it will be as before. What was read up to that point is kept.

3Send the results

Sending uploads the results of the tests you ran to peatcreative.com, where only Project Q's developer can read them. They are used only to make Project Q work with more models, never published. You can also save the file and email it instead.
